SKILLBRIDGE — WEBSITE FILES
===========================

WHAT IS INCLUDED
- Separate pages for Home, Discover, Learning, Projects, Scholarships, Competitions, Opportunities, Dashboard, and Announcements.
- A separate Admin interface with pages to plan management of resources, projects, scholarships, competitions, and announcements.
- Responsive navigation and search/filter interactions.
- Browser-local project saves and completion tracking.
- Footer credit: Created by Oluwajuwon / Graines Precious College.

IMPORTANT LIMITATIONS
- This is a static website suitable for GitHub Pages.
- The admin pages are interface prototypes only. They are not secure, have no real login, and cannot publish content.
- Student progress is stored only in the current browser/device; it is not an account and does not sync.
- Scholarship, competition, and opportunity pages use search links rather than a live verified database. Always verify details on the official organiser's website.
- Do not enter private or sensitive information into this prototype.
- To make admin publishing, secure login, and shared records genuinely work, connect a properly secured backend/database service.

HOW TO UPLOAD TO GITHUB
1. Download and extract skillbridge.zip.
2. Open your existing SkillBridge GitHub repository.
3. Upload the contents of the extracted skillbridge folder to the repository root.
   IMPORTANT: index.html must be directly in the repository root, not inside another nested skillbridge folder.
4. Commit the changes.
5. In Settings > Pages, choose your publishing source if it is not already configured.
6. Open the published site and test the navigation on mobile and desktop.
